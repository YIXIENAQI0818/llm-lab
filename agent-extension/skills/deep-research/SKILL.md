# 深度调研

## 执行步骤

1. **知识库搜索**：使用 search_docs 搜索知识库中的相关资料
2. **网络搜索**：使用 fetch__fetch 获取网络上的最新信息（如维基百科、官方文档等）
3. **对比分析**：对比不同来源的信息，找出共同点和分歧点
4. **撰写报告**：输出结构化报告，包含以下部分：
   - 概述（2-3 句话总结）
   - 核心发现（分点列出）
   - 不同观点（如有争议或分歧，列出各方立场）
   - 信息来源（列出所有查阅的资料及其来源）

## 完成标准

报告完整输出后，此 Skill 的任务即告完成。不要在没有新的明确调研请求时重复执行以上步骤。
